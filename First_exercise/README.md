# Formulario HTML y CSS

Este repositorio contiene una serie de ejercicios prácticos sobre formularios en HTML y estilos con CSS. Está pensado como cuaderno de aprendizaje para practicar maquetación, estructura de formularios y distintos tipos de inputs.

## 📌 Descripción

En este proyecto se trabajan conceptos básicos y avanzados de HTML como:

- formularios de contacto
- validaciones básicas
- inputs de texto, email, contraseña, número y archivo
- radio buttons y checkboxes
- selects y listas desplegables
- textareas
- diseño responsive
- maquetación con columnas y filas

## 🧩 Ejercicios incluidos

### 1. Formulario básico
Ubicación: `01_Class/`

Práctica inicial con un formulario sencillo para aprender:

- nombre
- email
- comentario
- botón de envío

### 2. Tabla de contactos
Ubicación: `02_Class/`

Se trabajan tablas y maquetación para presentar información estructurada en formato de contacto y listado de frutas.

### 3. Formulario con múltiples inputs
Ubicación: `03_class/`

Ejemplo avanzado con:

- búsqueda
- código postal
- teléfono
- contraseña
- email
- textarea
- número
- checkbox
- radio buttons
- select
- fecha
- upload de archivo

### 4. Formulario responsive
Ubicación: `04_Formulario_responsive/`

Se diseña un formulario con estructura adaptable para distintos tamaños de pantalla.

### 5. Formulario completo de registro
Ubicación: `05_formularioEjemplo/`

Este es el ejercicio más completo. Incluye:

- nombre y apellidos
- dirección
- código postal
- provincia
- email
- teléfono
- nivel de inglés
- disponibilidad
- aceptación de términos y condiciones

## ▶️ Cómo usarlo

No requiere instalación ni dependencias externas.

1. Abre la carpeta del ejercicio que quieras ver.
2. Ejecuta el archivo `.html` en tu navegador.
3. Si prefieres, puedes abrirlo desde VS Code con vista previa del navegador.

Ejemplo:

```bash
open 05_formularioEjemplo/formulrioEjemplo.html
```
